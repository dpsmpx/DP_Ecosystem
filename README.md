# DP_Ecosystem

Пошаговая симуляция экосистемы на Python и Pygame, где вода, растения, травоядные и хищники взаимодействуют в общей клеточной среде.

Проект рассчитан не на заранее заданный сценарий, а на наблюдение за тем, как система сама приходит к различным состояниям в зависимости от ресурсов, движения животных, погоды и случайности.

## Возможности

- клеточный мир с адаптивным размером сетки под разрешение экрана;
- вода с распространением по соседним клеткам и испарением;
- постоянные источники воды (родники);
- периодические дождевые тучи;
- рост и естественное угасание растений;
- травоядные, которые ищут пищу и могут убегать от хищников;
- хищники, которые преследуют травоядных и охотятся с вероятностью успеха;
- размножение обоих видов при выполнении условий по энергии;
- декомпозиция погибших от голода травоядных с возвратом биомассы почве;
- низковероятная миграция извне при критическом падении численности вида;
- ограничение максимальной численности популяций в зависимости от размера карты;
- статистика численности животных и количества клеток с водой;
- смена дня и ночи, влияющая на освещённость и поведение среды;
- интерактивный полив касанием или мышью.

## Модель мира

Мир представляет собой двумерную сетку. Каждая клетка может содержать запас воды, количество растительной биомассы и, при необходимости, одно животное.

### Вода

Вода:

- распределяется по соседним клеткам;
- испаряется пропорционально своему текущему количеству;
- поступает из родников;
- пополняется дождями;
- может быть вручную добавлена игроком.

Это создаёт локальные влажные зоны, вокруг которых поддерживается рост растений.

### Растения

Растения растут при достаточном освещении и наличии воды. Рост расходует воду.

Ночью рост прекращается, а растительная биомасса медленно уменьшается.

### Травоядные

Травоядные:

- питаются растениями в текущей клетке;
- ищут более богатые растительностью соседние клетки;
- при отсутствии подходящей пищи перемещаются случайно;
- могут замечать хищников на близкой дистанции и с некоторой вероятностью убегать;
- расходуют энергию;
- размножаются при достаточном запасе энергии;
- погибают при её полном истощении.

При смерти от голода часть биомассы возвращается в почву.

### Хищники

Хищники:

- ищут ближайших травоядных в радиусе охоты;
- преследуют жертву;
- имеют вероятностную успешность атаки;
- получают энергию после успешной охоты;
- расходуют энергию на существование;
- размножаются только после успешной охоты и при достаточном запасе энергии.

Если численность хищников критически падает, система может случайно добавить новую особь извне при наличии достаточного количества травоядных.

## Управление

| Действие | Управление |
|---|---|
| Полить область | Касание экрана / левая кнопка мыши |
| Завершить симуляцию | **Back** / **Esc** |
| Наблюдать за развитием мира | Ничего не нажимать |

Полив действует на небольшую область вокруг точки касания.

## Запуск

Требуется Python 3 и Pygame.

Установка зависимости:

```bash
python -m pip install pygame
```

Запуск:

```bash
python Ecosystem.py
```

Программа запускается в полноэкранном режиме и автоматически подстраивает размер клеточной сетки под доступное разрешение.

## Как устроена симуляция

Основной цикл на каждом такте выполняет следующие этапы:

1. обработка пользовательского ввода;
2. родники и дождь;
3. распространение и испарение воды;
4. рост растений;
5. шаг травоядных;
6. применение их перемещений и рождение новых особей;
7. шаг хищников;
8. удаление пойманных травоядных;
9. применение перемещений и размножения хищников;
10. сбор статистики;
11. отрисовка мира и HUD.

Для разрешения конфликтов движения используется общая функция `apply_moves()`, чтобы животные не исчезали из симуляции только из-за одновременного выбора одной и той же клетки.

## День и ночь

Полный цикл задаётся параметром:

```python
CYCLE_LEN = 600
```

Освещённость влияет прежде всего на рост и уменьшение растительности, а также на расход энергии животных.

## Параметры баланса

Основные коэффициенты экосистемы находятся непосредственно в `Ecosystem.py`. Среди них:

- `RAIN_CHANCE` — вероятность появления дождевой тучи;
- `EVAP_RATE` — скорость испарения;
- `PLANT_WATER_COST` — расход воды на рост растения;
- `FLEE_RADIUS` и `FLEE_CHANCE` — реакция травоядных на хищников;
- `CATCH_CHANCE` — вероятность успешной охоты;
- `DECOMP_PLANT` — возврат биомассы в почву после голодной смерти;
- `IMMIGRATION_CHANCE` — вероятность восстановления критически малой популяции.

Баланс намеренно допускает случайные колебания численности, но включает механизмы, уменьшающие вероятность необратимого коллапса всей системы.

## Отображение

Цвета клеток используются как визуальная индикация состояния:

- зелёный — растительность;
- синий — вода;
- жёлтый — травоядные;
- красный — хищники;
- тёмные оттенки — почва и низкая освещённость.

В верхней части экрана показывается положение текущей фазы дня, а HUD отображает численность популяций, их максимальные наблюдавшиеся значения и статистику воды.

## Текущий статус

Проект находится на стадии рабочего прототипа симуляции.

В последнем крупном обновлении баланса были исправлены несколько причин преждевременного разрушения экосистемы: отсутствие устойчивого источника воды, проблемы конфликтов перемещения, чрезмерно эффективная охота, слишком быстрое размножение и отсутствие возврата биомассы в почву.

По результатам этого обновления игровой цикл проверялся в headless-режиме на длинных сериях тактов с несколькими случайными seed'ами для оценки устойчивости популяций.
